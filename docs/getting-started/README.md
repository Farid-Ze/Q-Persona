# Getting Started with Q-Persona

Quick guides to help you get up and running with Q-Persona.

## 📚 Available Guides

### [QUICKSTART.md](./QUICKSTART.md)
**Get Q-Persona running in 5 minutes**

Perfect for developers who want to quickly explore the platform.

**What you'll learn:**
- Installation steps
- Running the development server
- Testing the API
- Connecting to a database
- Deploying to production

**Time required:** 5-10 minutes

### [SETUP_ENTERPRISE.md](./SETUP_ENTERPRISE.md)
**Enterprise setup and configuration guide**

**Time required:** 30-60 minutes
