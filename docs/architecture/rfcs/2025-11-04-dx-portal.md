# RFC: Developer Experience (DX) Portal

Goals
- Self-serve API adoption with zero tickets: docs, keys, logs, sandbox.

What
- Public docs page at `/docs/api` embedding Swagger UI backed by `/openapi.yaml`.
- `api_request_logs` table to power request log UI; instrumented v1 endpoints.
- UI at `.../settings/api-keys/[key_id]/logs` lists last 100 requests.
- Add per-key `usage_count` and `last_used_at` updates.

Next
- Add log retention policy + filtering (status, path, date).
- Add "Try it" sandbox with workspace-scoped mock key and CORS.
- Generate OpenAPI from source via tooling to avoid drift.
